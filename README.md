# Custom 3D Printing Venture

## 🎨 Overview

A thriving digital manufacturing startup specializing in high-quality custom 3D-printed products. We've scaled from concept to active operations, serving customers through multiple channels including **eBay storefronts** and a **physical retail shop**.

Operating a fleet of **25+ high-resolution printers**, we deliver small-batch production and distribution of:
- 🎌 **Anime merchandise** (figurines, collectibles, decorative pieces)
- 🔧 **Functional prototypes** (custom parts, tools, components)
- ⚙️ **Bespoke 3D designs** (tailored to customer specifications)
